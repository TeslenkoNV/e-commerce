# 🛍️ Интернет-магазин одежды
![Интернет-магазин](Nome_collage.jpg)

Адаптивное одностраничное приложение с каталогом товаров, фильтрацией, корзиной и отображением пунктов выдачи на карте.

## 🚀 Технологии

- **React**
- **Vite**
- **JavaScript**
- **Tailwind CSS**
- **Bootstrap**
- **Яндекс.Карты API**

## 🔧 Функциональность

- Каталог товаров с карточками
- Фильтрация по категориям
- Корзина с добавлением и удалением товаров
- Валидация форм
- Интеграция с **Яндекс.Картами API** для отображения пунктов самовывоза
- Адаптивная вёрстка под мобильные и десктопные устройства
- Разделение компонентов, управление состоянием

## 📦 Структура проекта

- `components/` — UI-компоненты (каталог, карточки, корзина и т.д.)
- `pages/` — страницы приложения
- `utils/` — утилиты и вспомогательные функции
- `assets/` — изображения и стили

## 🧠 Чему научилась

- Созданию архитектуры SPA с нуля
- Интеграции стороннего API (карты)
- Использованию Tailwind для быстрого прототипирования интерфейсов
- Разделению логики по компонентам
- Настройке проекта с Vite

## 🔧 Установка и запуск

1. Клонируйте репозиторий:
    ```bash
    git clone [https://github.com/TeslenkoNV/e-commerce.git](https://github.com/TeslenkoNV/e-commerce.git)
    ```

2. Перейдите в директорию проекта:
    ```bash
    cd e-commerce
    ```

3. Установите зависимости:
    ```bash
    npm install
    ```

4. Запустите проект:
    ```bash
    npm run dev
    ```

5. Откройте браузер и перейдите по адресу [http://localhost:3000](http://localhost:3000) для просмотра приложения.
